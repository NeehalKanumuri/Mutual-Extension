Installation Guide · The Mutual

Install The Mutual directly into Google Chrome, Brave, Arc, or Microsoft Edge.

1. Download the-mutual-extension-chrome.zip and unzip it.
2. In Chrome, navigate to your extensions page:
chrome://extensions
3. In the top-right corner, toggle on Developer mode.
4. Click Load unpacked and select the unzipped directory.
5. Pin The Mutual in your browser toolbar!
Download Chrome Extension (.zip)

The Mutual is packaged as a native macOS App (The Mutual.app) with an embedded Safari extension bundle.

1. Download and extract the macOS package.
2. In Terminal, run the launch script:
./launch_safari.sh
3. In Safari: Open Settings → Advanced → Check "Show features for web developers".
4. In menu bar: Develop → Allow Unsigned Extensions.
5. In Safari → Settings → Extensions: Enable "The Mutual".
